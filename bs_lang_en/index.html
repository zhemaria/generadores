⚙️ Groq API Configuration

🔑 Why do you need an API key?

This generator uses Groq's free API to create questions. You can pick the model below — Llama 3.3 70B is the default. Each teacher should use their own personal key, which you can get for free in under a minute. Your key stays in your browser and is never shared with anyone else.

📝 Steps to get your free key

  1. Go to console.groq.com/keys
  2. Sign up with your email or Google account (no credit card needed)
  3. Click "Create API Key"
  4. Copy the key (it starts with gsk_...)
  5. Paste it in the field below and click Save

🔐 Your key stays in your browser

Your key is stored only in your browser (local storage). It is never sent to any external server other than Groq's API when you generate questions. No one else can see it.

📚 How to Use the Quiz Generator

🎯 Basic Steps

1. Select question type (Multiple Choice, True/False, etc.)

2. Set the number of questions to generate

3. Choose difficulty level and focus area

4. Upload a PDF (optional) or describe your topic

5. Click "Generate Questions" and AI will create your quiz

6. Download the CSV when satisfied with the questions

🌍 ESL/ELL Special Features

• Vocabulary Focus: Questions emphasize key vocabulary in context

• Grammar Scaffolding: Questions at appropriate complexity levels

• Cultural Sensitivity: Content considers diverse backgrounds

• Clear Language: Avoids idioms and complex sentence structures at beginner/intermediate levels

• Visual Support: Hints provide context clues for comprehension

📊 Brightspace D2L CSV Format

• Generated CSV is 100% compatible with Brightspace D2L

• UTF-8 format with all required columns

• Supports: MC, MS, TF, SA, WR, M, O (Ordering)

• Hints included in each question's Hint field

📤 How to Import into Brightspace

1. Go to your course in Brightspace

2. Access Quizzes → Question Library

3. Click Import → Upload a file

4. Select your downloaded CSV file

5. Review and confirm the import

📘 Subject-Specific Tips

Math: Use "Problem Solving" focus for word problems requiring multiple steps

Language Arts: Use "Analysis" focus for reading comprehension and literary analysis

ESL/ELL: Start with "Basic" difficulty and "Conceptual" focus for vocabulary building
