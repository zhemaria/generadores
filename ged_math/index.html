⚙️ Configuración de API de Groq

🔑 ¿Por qué necesitas una API key?

Este generador utiliza el modelo Llama 3.3 70B a través de la API gratuita de Groq para crear preguntas. Cada profesor debe usar su propia clave personal, que se obtiene de forma gratuita en menos de un minuto.

📝 Pasos para obtener tu clave gratuita

  1. Ve a console.groq.com/keys
  2. Regístrate con tu correo o cuenta de Google (no necesitas tarjeta de crédito)
  3. Haz clic en "Create API Key"
  4. Copia la clave (empieza con gsk_... )
  5. Pégala en el campo de abajo y haz clic en Guardar

🔐 Tu clave en tu navegador

Tu clave se guarda únicamente en tu navegador (almacenamiento local). No se envía a ningún servidor externo más que a la API de Groq cuando generas preguntas. Nadie más puede verla.

📘 Guía del Generador HTML

🎯 ¿Qué hace este generador?

Crea cuestionarios interactivos de matemáticas en formato HTML autocontenido, ideales para publicar en GEDparaHispanos o cualquier sitio web. Cada cuestionario incluye feedback específico para cada respuesta — incluso para los distractores — explicando el error común que produce esa respuesta.

📋 Tipos de pregunta soportados

• Opción múltiple: 4 opciones, una correcta. La forma más recomendada para feedback rico.

• Respuesta múltiple: varias respuestas correctas (2-3).

• Verdadero/Falso: afirmaciones matemáticas.

• Respuesta corta: el estudiante escribe la respuesta numérica.

⚙️ Niveles de dificultad

• Básico: GED nivel 1, operaciones fundamentales

• Intermedio: GED nivel 2, problemas de 2-3 pasos

• Avanzado: GED nivel 3, aplicaciones complejas

• Experto: múltiples conceptos combinados

📝 Enfoques disponibles

• Problemas de palabras: situaciones reales, contextos prácticos

• Cálculo directo: ejercicios sin contexto narrativo

• Conceptual: comprensión de principios

• Análisis de datos: interpretación de gráficas y tablas

💡 Flujo de trabajo

1. Configura los parámetros (tipo, cantidad, área, nivel...)

2. Escribe el tema en el chat o sube un PDF

3. Pulsa Generar — la IA crea las preguntas con feedback

4. Pulsa Vista previa para probar el cuestionario aquí mismo

5. Pulsa Descargar HTML y súbelo a GitHub Pages o donde quieras
