Getting your free Groq key, and what the free tier can actually do (read this first)

Setting up your key (2 minutes)

  1. Go to console.groq.com/keys and create an account with your email, GitHub or Google. No credit card required.
  2. Click Create API Key, name it, and copy it immediately: it is shown only once.
  3. Paste it in the field above. It is stored only in this browser (localStorage) and never sent to any server of mine.
  4. Press ↻ to load the list of currently available models.

What the free tier can and cannot do

Groq caps tokens per minute (TPM) per model, counting your request and the reply together. On the free plan, Llama 3.3 70B allows about 12,000 TPM and GPT-OSS 120B about 8,000. Those numbers change; the meter above reads the real limit for your account from Groq’s own response headers, so trust the meter over this paragraph.

The rulebook this tool sends the model is long, because MyOpenMath question code is unforgiving. It is trimmed automatically — coordinate-plane and table rules are only included when your exercise actually needs them — but some combinations still do not fit. Measured on Llama 3.3 70B:

Estimated request size by combination, against a 12,000 TPM free-tier limit
Combination Approx. tokens Free tier
Arithmetic or algebra · multiple choice8,000Comfortable
Arithmetic or algebra · open answer9,600Comfortable
Geometry · multiple choice10,200Tight
Statistics with a data table10,200Tight
Geometry · open answer11,700Tight
Anything with a coordinate plane, line or graph12,700Does not fit

What to do about it. “Tight” means it works, but wait roughly a minute between generations or the second request collides with the quota. “Does not fit” means slopes, intercepts, graphed lines and scatter plots are out of reach on the free plan — not because the tool is failing, but because the rules needed to make MyOpenMath draw a correct coordinate plane are themselves larger than the free minute allows.

If graphing questions matter to you, the honest answer is to add a few dollars of credit on Groq’s Developer plan. It raises the ceiling to roughly 250,000–300,000 TPM, which removes this constraint entirely and costs cents per question. Until then, this tool is genuinely useful for arithmetic, algebra and non-graphing geometry, which is most of a GED math course.

One more thing. The generated code is reviewed automatically before you see it (LaTeX leaks, impossible triangles, deadlocked where clauses, figures that run off the frame, answer types that would reject a correct exact answer). Read the validator panel. It is a heuristic, not a guarantee — always open the preview before pasting into MyOpenMath.
