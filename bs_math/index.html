⚙️ Configuración de API de Groq

🔑 ¿Por qué necesitas una API key?

Este generador utiliza la API gratuita de Groq para crear preguntas. Puedes elegir el modelo más abajo; Llama 3.3 70B es el predeterminado. Cada profesor debe usar su propia clave personal, que se obtiene de forma gratuita en menos de un minuto.

📝 Pasos para obtener tu clave gratuita

  1. Ve a console.groq.com/keys
  2. Regístrate con tu correo o cuenta de Google (no necesitas tarjeta de crédito)
  3. Haz clic en "Create API Key"
  4. Copia la clave (empieza con gsk_...)
  5. Pégala en el campo de abajo y haz clic en Guardar

🔐 Tu clave en tu navegador

Tu clave se guarda únicamente en tu navegador (almacenamiento local). No se envía a ningún servidor externo más que a la API de Groq cuando generas preguntas. Nadie más puede verla.

🤖 Modelo

Guarda tu clave para cargar la lista de modelos en vivo desde Groq.

Nota sobre el cupo gratuito: Groq limita los tokens por minuto de cada cuenta. Si aparece un aviso de cupo, genera menos preguntas de una vez (5 en lugar de 20), espera un minuto, usa un PDF más corto o elige otro modelo de la lista. 📐 Guía - Generador de Matemáticas

🎯 Especialización Matemática

Este generador está optimizado para matemáticas : aritmética, álgebra, geometría, estadística, cálculo y más.

Los prompts están diseñados para generar problemas que requieren razonamiento de múltiples pasos , no simples operaciones.

📊 Tipos de Contenido Matemático

• Aritmética: Operaciones, fracciones, decimales, porcentajes

• Álgebra: Ecuaciones, expresiones, funciones, sistemas

• Geometría: Áreas, perímetros, volúmenes, teoremas

• Estadística: Media, mediana, probabilidad, gráficas

• Cálculo básico: Límites, derivadas, integrales sencillas

🔢 Notación Matemática

• Las expresiones se muestran profesionalmente en pantalla (x², √x, π)

• En el CSV se exportan en Unicode compatible con Brightspace

• Ejemplos: x^2 → x², sqrt(16) → √16, 1/2 → ½, pi → π

⚙️ Niveles de Dificultad

• Básico: GED nivel 1, operaciones fundamentales

• Intermedio: GED nivel 2, problemas de 2-3 pasos

• Avanzado: GED nivel 3, aplicaciones complejas

• Experto: Desafíos matemáticos, múltiples conceptos

📝 Enfoques Disponibles

• Problemas de palabras: Situaciones reales, contextos prácticos

• Cálculo directo: Ejercicios de práctica computacional

• Conceptual: Comprensión de principios matemáticos

• Análisis de datos: Interpretación de gráficas y tablas

🎯 Cómo se respetan tus restricciones

Lo que escribes en el campo de texto es una orden de prioridad absoluta y se envía al modelo aunque tengas PDFs cargados. Los PDFs pasan a ser material de apoyo (vocabulario, nivel y estilo).

• Redacta la restricción en positivo y en negativo: «Divide un polinomio entre un monomio. El divisor SIEMPRE será un monomio; NUNCA un binomio ni un trinomio.»

• Con 🔍 Verificar y corregir (2.ª pasada) activado, el modelo revisa su propia lista y sustituye las preguntas que no cumplan tu restricción antes de pasarlas al CSV.

• El selector Notación matemática decide el formato de salida: Unicode (x², √, ÷) para máxima compatibilidad con Brightspace, o LaTeX entre \( y \) si prefieres que Brightspace renderice las ecuaciones. Prueba primero un cuestionario corto en tu curso antes de importar uno largo en LaTeX.

• El Identificador de preguntas es opcional: si lo dejas en blanco, el CSV no incluye las filas ID ni Title y Brightspace usa el propio enunciado como título.

💡 Tips para Mejores Resultados

• En el campo de texto, especifica el tema exacto (ej: "ecuaciones lineales de primer grado")

• Puedes subir PDFs con contenido del que quieras extraer problemas

• Los hints dan pistas pedagógicas sin revelar la respuesta

• Usa "Problemas de palabras" para contextos realistas del GED
