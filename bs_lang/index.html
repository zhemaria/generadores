⚙️ Configuración de API de Groq

🔑 ¿Por qué necesitas una API key?

Este generador utiliza la API gratuita de Groq para crear preguntas. Puedes elegir el modelo más abajo; Llama 3.3 70B es el predeterminado. Cada profesor debe usar su propia clave personal, que se obtiene de forma gratuita en menos de un minuto.

📝 Pasos para obtener tu clave gratuita

  1. Ve a console.groq.com/keys
  2. Regístrate con tu correo o cuenta de Google (no necesitas tarjeta de crédito)
  3. Haz clic en "Create API Key"
  4. Copia la clave (empieza con gsk_...)
  5. Pégala en el campo de abajo y haz clic en Guardar

🔐 Tu clave en tu navegador

Tu clave se guarda únicamente en tu navegador (almacenamiento local). No se envía a ningún servidor externo más que a la API de Groq cuando generas preguntas. Nadie más puede verla.

📚 Guía - Generador de Artes del Lenguaje

🎯 Especialización en Lenguaje

Este generador está optimizado para español : comprensión lectora, gramática, ortografía, vocabulario y redacción.

Los prompts generan preguntas que evalúan habilidades lingüísticas reales según estándares del GED en español.

📊 Áreas de Contenido

• Comprensión lectora: Ideas principales, detalles, inferencias, propósito del autor

• Gramática: Concordancia, tiempos verbales, pronombres, estructura oracional

• Ortografía: Acentuación, uso de letras, signos de puntuación

• Vocabulario: Significado en contexto, sinónimos, antónimos, cognados

• Redacción: Organización de ideas, transiciones, coherencia textual

📝 Tipos de Textos

• Informativos: Artículos, ensayos, noticias, textos científicos

• Literarios: Narrativa, poesía, drama, biografías

• Funcionales: Cartas, instrucciones, formularios, anuncios

• Argumentativos: Opinión, debate, persuasión

⚙️ Niveles de Dificultad

• Básico: Comprensión literal, gramática elemental

• Intermedio: Inferencias simples, análisis gramatical

• Avanzado: Análisis crítico, síntesis de información

• Experto: Evaluación, comparación de perspectivas

💡 Tips para Mejores Resultados

• Sube textos o lecturas específicas para generar preguntas basadas en ellas

• Para comprensión lectora , el sistema genera un pasaje y preguntas relacionadas

• Especifica el tipo de texto que deseas (narrativo, informativo, etc.)

• Los hints guían al estudiante hacia la estrategia de lectura correcta

🔗 Emparejamiento (matching)

Útil para mayúscula → minúscula , sinónimos, antónimos, palabra → categoría gramatical, etc.

• Modalidad MC (opción múltiple): cada par se convierte en una pregunta con 4 opciones. Ideal para celular y estudiantes que prefieren no teclear.

• Modalidad MA (respuesta corta múltiple): una pregunta agrupa 4-8 pares; el estudiante escribe cada respuesta. Más fiel al concepto de "matching" tradicional.

Brightspace D2L no soporta el tipo "Matching" nativo en CSV v4.0, así que se simula con MC o MA (Multi-Short Answer). Selecciona un dominio predefinido o usa Personalizado para describirlo en el chat.

📖 Sobre Comprensión Lectora

Cuando seleccionas "Comprensión lectora", el sistema:

1. Genera o usa un pasaje de lectura apropiado

2. Crea preguntas que evalúan diferentes niveles de comprensión

3. Incluye preguntas sobre idea principal, detalles, vocabulario e inferencias

🔗 Sobre Emparejamiento (MC simulado)

Brightspace D2L no soporta matching nativo vía CSV, así que este modo lo simula como una serie de preguntas de opción múltiple — una por cada par.

Dominios disponibles: mayúscula→minúscula, minúscula→mayúscula, sinónimos, antónimos, singular→plural, masculino→femenino, verbo conjugado→infinitivo, palabra→categoría gramatical, palabra→tipo de acentuación, y personalizado.

Funcionamiento: cada pregunta presenta un elemento (ej. "A") y 4 opciones donde solo una es la pareja correcta (ej. *a) a). Ideal para estudiantes adultos en celular que no quieren teclear.

Tip: cambia el "Identificador" a algo como EMPAR o MATCH para distinguirlas en tu banco de preguntas.
